## 1. 当前配置（`application/robot_def.h`）

```c
// #define ONE_BOARD        // 单板控制整车
//#define CHASSIS_BOARD      // 底盘板   ← 当前被注释
 #define GIMBAL_BOARD       // 云台板   ← 当前打开（构建云台固件时）
//#define CHASSIS_RC_DIRECT  // 单板直控（遥控器接底盘板、直控底盘）
// #define RC_RECEIVER_ON_CHASSIS // 遥控器接底盘板 + 经CAN转发给云台板
// #define GIMBAL_YAW_POSITION_LOOP // 大yaw 位置环（默认关闭=速度环）
// #define GIMBAL_YAW_FEEDBACK_IMU  // 大yaw 用IMU反馈（默认关闭=用电机自身编码器）
 #define GIMBAL_YAW_IMU_HOLD       // 大yaw 世界角保持（当前打开；小陀螺直行/松杆钉角度靠它）
 #define GIMBAL_YAW_FF_ON_IMU_LOST // IMU 失效时自动切"小陀螺开环前馈"兜底（常数在线自学）
// #define GIMBAL_YAW_FF_FORCE       // 强制走开环兜底（关掉保持环）—— 现场验证兜底方向用
```

**注意**：构建哪块板就打开哪个宏（只能有一个）。改完必须 `ninja` 重新编译，否则烧的还是旧固件。
**烧录工具不做板型自检**：`jlink_tool.py flash` 写的就是 J-Link 当前挂着的那块板；换板型后还要注意
`basic_framework.elf` 的符号是否与目标板同源（见 §2 末）。

## 2. 编译与烧录

```powershell
# ① 编译（先确认 robot_def.h 的板型宏）
$env:PATH="D:\STM32CUBECLT\STM32CubeCLT_1.22.0\GNU-tools-for-stm32\bin;D:\STM32CUBECLT\STM32CubeCLT_1.22.0\Ninja\bin;$env:PATH"
cd D:\traeproject\2026Kinetic_Infantry_withUIC\robot

# ② 烧录（J-Link 插在哪块板就烧哪块）
cd $env:TEMP\jlink_dsh
python jlink_tool.py flash            # 烧 cmake-build-verify\basic_framework.hex（当前 build 的产物）
python jlink_tool.py flashfile <path> # 烧指定 hex（例如归档的 gimbal_fixed.hex）
```

**两板固件归档约定**（本仓库习惯）：

| 文件 | 内容 |
| --- | --- |
| `cmake-build-verify\basic_framework.hex/.elf` | **最后一次编译**的产物（符号解析也用它，注意会随板型变化） |
| `cmake-build-verify\gimbal_fixed.hex/.elf` | 云台板固件归档副本 |

**烧录流程（两块板时）**：切到 `GIMBAL_BOARD` → `ninja` → 复制成 `gimbal_fixed.*` → 切回 `CHASSIS_BOARD` → `ninja` → 先烧底盘 → 把 J-Link 挪到云台板 → `flashfile gimbal_fixed.hex`。
读寄存器/内存前**务必确认 `basic_framework.elf` 与目标板固件同源**，否则符号地址对不上（本会话踩过多次）。

**烧完怎么确认"烧的是哪块板"**（工具不会告诉你，两条 30 秒自证）：

| 判据 | 含义 |
| --- | --- |
| `peek 080E0000 32` → **全 `FF`** | Flash 扇区 11 没有底盘舵轮现场标定记录 ⇒ 目标不是存过标定的底盘板 |
| `comm` → `daemon temp_count=100 -> ONLINE` | 收到对端 `0x311` 上行帧（云台板只发 `0x312`）⇒ 对端是底盘板 ⇒ 本板是**云台板** |

## 3. 现场操作

### 3.1 上电顺序

1. 遥控器开机、接收机 LED **常绿**（常绿=已对频）
2. 整车/云台上电（**双板启动要等几十秒**做 BMI088 零飘标定；启动完成前不要操作遥控器）
3. 左开关过一遍 **[中]** → 听到/看到 `[CMD] reinstate, robot ready`（或直接进入下一步操作）

### 3.2 驾驶（底盘）

- 左**[下]** + 右**[中]**（不跟随）→ 右摇杆：前推=前进，后拉=后退，左右=平移
- 右**[上]** = 小陀螺（底盘自旋 + 平移）；右**[下]** = 跟随云台（底盘转向对齐云台，需谨慎，车会转）
- **小陀螺前进方向 = 大yaw（枪口）朝向**：底盘转、枪口不转，摇杆前推就沿枪口方向直行（画圈问题见 §9.23）；
  注意该档位平移系数是 `5.0`（另两档 `25.0`），所以**小陀螺的前进速度只有其它档的 1/5**
- 速度：右摇杆满杆 = `660×25 = 16500`（`CHASSIS_WHEEL_SPEED_MAX` 满量程）
- 松杆后舵轮会**主动回到正前方**（`CHASSIS_STEER_RETURN_ON_STOP`）

### 3.3 大 yaw（云台）

- 左**[下]**（遥控器控制档，三档都用右开关决定底盘模式）→ **左摇杆水平**：右推=一个方向，左推=反向
- 满杆约 **119°/s**（系数 `GIMBAL_YAW_RC_SCALE = 0.0009`/拍 @200Hz）
- 当前用**速度环 + 世界角保持**：推杆时纯速度控制（跟手），**松杆后钉住当前朝向**（被外力推动会回弹；
  这是小陀螺能直行的前提）；零力/急停后重新使能时会自动对齐当前指向，不会跳
- 小陀螺里边推左杆边瞄：瞄准速率 = 摇杆速率 **+ 底盘自转速率**（保持环在推杆期间让位），会偏快
- 左摇杆竖直 = pitch（仅右[中]档有效；当前只挂了大yaw电机，pitch 未接）

### 3.4 舵轮"正前方"现场标定（示教 + 存 Flash）

| 步骤 | 操作 | 现象 |
| --- | --- | --- |
| 进入 | 左**[中]** + 右**[下]** 保持 1.5 s | 底盘 RTT 打 `steer teach ON`；四舵轮**断电可用手自由摆动** |
| 摆放 | 用手把四个舵轮摆到视觉正前方 | 舵轮无力矩 |
| 保存 | 右摇杆**前推到底保持 1.0 s** | 底盘打 `steer calib SAVED to flash: …`，随后自动回正 |
| 恢复出厂 | 右摇杆**后拉到底保持 1.0 s** | 底盘打 `steer calib ERASED, back to robot_def.h defaults` |
| 退出 | **把左开关离开[中]**（打[下]或[上]） | 底盘打 `steer teach OFF`，用（新）标定重跑一次回正 |

⚠️ 示教期间**不要动左开关**，一动就退出且不保存。上电日志若为 `steer calib from flash` 说明用的是现场标定值（否则用 `robot_def.h` 默认值）。

## 4. 参数速查（要改哪个数就改这里）

| 想调什么 | 位置 | 现值 | 说明 |
| --- | --- | --- | --- |
| 大yaw 摇杆灵敏度 | `robot_def.h GIMBAL_YAW_RC_SCALE` | `0.0009` | 每拍角度增量；满杆 = 值×660×200 °/s |
| 大yaw 最大角速度（兜底） | `robot_def.h GIMBAL_YAW_SPEED_LIMIT` | `200.0` °/s | 越权限幅，和摇杆系数无关 |
| 大yaw 摩擦前馈 | `robot_def.h GIMBAL_YAW_FRICTION_FF` | `2500` | 满量程 20000；太小=起步无力/慢慢爬，太大=低速比指令快 |
| 大yaw **世界角保持** 增益 | `robot_def.h GIMBAL_YAW_HOLD_KP` | `8.0` (1/s) | 底盘自旋 ω 时瞄准有 **ω/Kp** 固定偏差（150°/s→约19°）；嫌偏加大、抖动减小 |
| 大yaw 保持环限幅 | `robot_def.h GIMBAL_YAW_HOLD_LIMIT` | `150.0` °/s | 保持环单独贡献的速率上限（总限幅仍是 `GIMBAL_YAW_SPEED_LIMIT` 200°/s） |
| 大yaw 保持环"让位"阈值 | `robot_def.h GIMBAL_YAW_HOLD_STICK_TH` | `3.0` °/s | 摇杆速率超过它即视为"人在操作"，保持环让位并把目标刷新为当前指向 |
| 小陀螺兜底速率（IMU 失效时用） | `robot_def.h GIMBAL_YAW_SPIN_FF_RATE` | `58.0` °/s | 只是**初值**（几何估算）；正常运行中会被**在线自学值**覆盖（保持环在"小陀螺+松杆"的稳态输出≈该速率）。现场可在小陀螺里看日志 `I:[gimbal] spin FF learned = ±… mdeg/s`（每秒一行）确认学到了多少 |
| 兜底自学速度 / 可信上限 | `robot_def.h GIMBAL_YAW_FF_LEARN_ALPHA / _SPIN_FF_MAX` | `0.002` (τ≈0.5 s) / `300` °/s | 先稳定 1 s 再学；越界即丢弃 |
| 大yaw 速度环 PID | `gimbal.c` `yaw_config.speed_PID` | `Kp=10 Ki=0.5 Kd=0` | **单位是 °/s**（不是 RPM！）；参考底盘板 `Kp=10/Ki=0.1` |
| 大yaw 位置环 PID（若启用位置环） | `gimbal.c` `yaw_config.angle_PID` | `Kp=50…MaxOut=1000` | `MaxOut` 单位是**速度参考 °/s**，启用前务必按 °/s 重新整定 |
| 底盘驾驶速度 | `chassis.c CHASSIS_RC_SPEED_SCALE`（单板直控）/ `robot_cmd.c` 的 ×25 | — | 双板标准映射是 ×25（原设计满量程） |
| 舵轮正前方角度 | `robot_def.h GM6020_{LF,RF,LB,RB}_ANGLE` | 133.40/223.93/102.15/134.19 | 优先用示教存 Flash，无需重编译 |
| 舵轮回正容差/超时 | `chassis.c CHASSIS_ALIGN_TOLERANCE_DEG / TIMEOUT_MS` | 2.0° / 8000 ms | 容差越大越快结束，越小越准但更久 |
| 遥控器死区 | `robot_def.h GIMBAL_DEAD_BAND / CHASSIS_DEAD_BAND` | 10 / 10 | 摇杆量纲 ±660 |

## 5. 回退开关（都是改宏 + 重编译 + 烧录）

| 想回到… | 操作 | 需要刷哪块 |
| --- | --- | --- |
| 关掉"大yaw 世界角保持"（回到纯速度环：松杆只停转、不钉角度，**小陀螺会恢复画圈**） | 注释 `#define GIMBAL_YAW_IMU_HOLD` | 云台板 |
| 只留开环兜底（完全不用 IMU 姿态：小陀螺能直行但方向会慢慢弧） | 注释 `GIMBAL_YAW_IMU_HOLD`，保留 `GIMBAL_YAW_FF_ON_IMU_LOST`（此时兜底常态生效，自学值失效、只用初值/改用手量值） | 云台板 |
| 现场验证/校准兜底方向 | 打开 `GIMBAL_YAW_FF_FORCE`（关掉保持环只走兜底）→ 小陀螺看是否直行；**反了的表现是"画得更紧"**，把 `GIMBAL_YAW_SPIN_FF_RATE` 取反 | 云台板 |
| 大yaw 用 **IMU 绝对指向**（原设计，供视觉/跟随） | 打开 `#define GIMBAL_YAW_FEEDBACK_IMU` | 云台板 |
| 大yaw 用 **位置环**（松杆钉住角度） | 打开 `#define GIMBAL_YAW_POSITION_LOOP`（**先按 °/s 量纲重新整定 `angle_PID`**，否则会像 §9.21 那样堵转后满速冲出） | 云台板 |
| 回到 **单板直控**（遥控器接底盘板，只用地盘板） | 打开 `CHASSIS_RC_DIRECT`、注释 `GIMBAL_BOARD`、打开 `CHASSIS_BOARD` | 底盘板 |
| 遥控器接**底盘板**但走双板转发 | 打开 `RC_RECEIVER_ON_CHASSIS` + `CHASSIS_BOARD`（云台板同宏） | 两块（且 0x311 上行 42B/6 帧，需先做附录A 的降载） |
| 回到 **单板整车** | 打开 `ONE_BOARD`，其余注释 | 只刷一块 |

**回退前的自检清单**：① 宏只有一个板型 ② `ninja` 0 error ③ 烧录后回读 PASS（工具会逐字节校验）④ `status` 看到 `BSP_FaultCode=0`、`IMU_Available=1` ⑤ 遥控器在线、过一遍左[中]。

## 6. 出问题先看什么（排查决策树）

| 现象 | 先查 | 命令/判据 |
| --- | --- | --- |
| 遥控器完全没反应 | 接收机 LED、DBUS 是否插在云台板 USART3 口 | `python usart3diag.py gimbal`（`NDTR=18` 且值不变 ⇒ 一个字节都没收到）；`usrscan.py` 看是否插到别的串口 |
| 云台板 `rc_online=0` | 遥控器是否开机、接收机是否对频 | `jlink_tool.py status gimbal` |
| 底盘不动 | ① 左开关是否在[下] ② 板间链路 | 左[下] 时 `cmdwatch` 应看到 `mode=NO_FOLLOW` 且 `vx/vy` 随摇杆变；`jlink_tool.py comm` 看 `resync/crc/tail` 与 daemon |
| 云台/底盘"能动但方向不对" | 先确认是"视觉朝后但推力正确"还是真反向 | 舵轮：`jlink_tool.py align` 看四轮残差；大yaw：`GIMBAL_YAW_FEEDBACK_IMU`/`motor_reverse_flag` |
| 大yaw 不动 | ① 电机是否在 CAN2 且有 24V ② 电机反馈是否有值 | 读 `CAN2 ESR`（`TEC>0 / LEC=3` = 总线上没有第二个节点 ⇒ 接线/供电问题，**不是 ID 问题**——ID 错也会回 ACK）；`yaw_motor temp=0` 即无反馈 |
| 大yaw 抖动/自激 | 速度环增益是否按 **°/s** 量纲取（`Kp≈10`） | `yawdiag.py` 看 `sOut` 是否在 ±20000 翻转 |
| **小陀螺推前进变画圈** | ① `GIMBAL_YAW_IMU_HOLD` 是否打开 ② 小陀螺时大yaw 是否被底盘带着一起转 ③ IMU 姿态是否有效 | 大yaw 跟着转 ⇒ 保持环没生效（宏被注释 / `BigYaw_Feed` 为 NaN / `IMU_Available=0`）；`status gimbal` 看 `IMU_Available`，`yawwatch` 看 `BigYaw` 与电机角（§9.23） |
| 小陀螺**直行但方向偏**（固定偏角） | 保持环的 ω/Kp 稳态偏差 | 偏角 ≈ 底盘自转角速度 ÷ `GIMBAL_YAW_HOLD_KP`；加大 Kp（或后续加外环积分） |
| 大yaw 松杆后自己转回/回弹 | 这是世界角保持的**正常行为** | 不要就注释 `GIMBAL_YAW_IMU_HOLD` |
| IMU 挂了（`IMU_Available=0` 或姿态 NaN）时小陀螺表现 | 应自动切到开环兜底（仍直行但可能缓慢画弧） | `status gimbal` 看 `IMU_Available`；`peek` 看自学值是否非 0（§9.24） |
| 大yaw **缓慢自转**（松杆也在走） | IMU 零偏/姿态漂移（标定失败时约 0.43°/s）或姿态**冻结** | 上电后别碰车让它跑完 3 s 标定；`yawdrift.py` 量漂移；姿态冻结属已知待加固项 |
| 示教存不进去 / 示教退不出来 | 底盘侧能否读到新命令字节 | `jlink_tool.py cmdwatch`：`teach` 字节应随操作变化（0/1/2）；底盘 RTT 应有 `steer teach ON/OFF`、`steer calib SAVED` |
| Flash 标定没生效 | 记录是否有效 | `jlink_tool.py calib`（magic/checksum + RAM 生效值） |
| 启动很久没反应 | BMI088 零飘标定（本板慢，几十秒） | `jlink_tool.py boottime` / 看 `IMU_Available` 何时变 1 |

### 调试工具清单（`%TEMP%\jlink_dsh\`）

| 脚本/命令 | 用途 |
| --- | --- |
| `jlink_tool.py flash / flashfile` | 烧录 + 全片回读校验 |
| `jlink_tool.py status [gimbal]` | 故障码/IMU/指令/CANComm 实例/遥控器状态 + RTT 尾部 |
| `jlink_tool.py comm` | 板间链路质量：`resync/crc_err/tail_err` + daemon 在线 |
| `jlink_tool.py calib` / `align` | 舵轮 Flash 标定记录 / 四轮残差与 `steering_dirt` |
| `jlink_tool.py cmdwatch [sec]` | 底盘侧**不停机**采样 `chassis_cmd_recv`（含 teach 字节）+ 链路 |
| `jlink_tool.py rcwatch [sec] [period] gimbal` | 云台侧采样遥控器/转发指令 |

## 7. 已知问题与注意事项

1. **DBUS 链路会偶发失效**（本会话出现 3 次）：表现是 `rc_online=0`、`usart3diag` 显示 `NDTR` 不变。多数靠**重新插紧接收机插头**恢复 ⇒ 建议换一根 DBUS 线/插座。
2. **J-Link 不稳定**：USB 会掉线（设备管理器出现"描述符请求失败"）、SWD 偶发 2 分钟阻塞。经验：**4000 kHz 能连，1000 kHz 反而失败**；新脚本已带连接重试；必要时拔插 USB。
3. **大yaw 电机必须接 CAN2**（固件 `hcan2, tx_id=2`）；CAN1 是板间通信口。
4. **双板启动要等 IMU 零飘标定**：标定成功只需 **~3 s**（`CaliTimes=6000×0.5 ms`），但**那 3 秒必须别碰车**；被晃动时它一轮轮重试、最长拖到 **12 s** 上限才放弃并改用离线常数。启动期间遥控器操作无效属正常。
11. **标定失败不影响使用（实测）**：失败后用离线常数时 `BigYaw` 漂移 **−0.43 °/s**（小陀螺推 3 秒 ≈ 1.3°，可忽略；1 分钟约 26° 才需重新对方向）。注意**跳过标定只会让漂移更大**（gx/gy 残余零偏 0.47/−0.82 °/s 会漏到航向）——想少依赖 IMU 请用 `GIMBAL_YAW_FF_ON_IMU_LOST` 那条兜底（§9.24），而不是关掉标定。
12. **（已知不足，未加固）** `INS_IMUIsAvailable()` 只覆盖"初始化失败"；若 IMU **运行中 SPI 失效**（值冻结而非 NaN），保持环会拿冻结值闭环 ⇒ 最坏几十 °/s 缓慢自转（可用急停/左开关恢复）。加固做法：电机在转但 `BigYaw` 连续 200 ms 不动 ⇒ 判冻结、关保持环切兜底。
5. **RB（右后）舵轮**满输出下转速明显偏低（约 3~4°/s）：属硬件/机械问题（待断电手转比对阻力、看 GM6020 指示灯、DJI Assistant 对比电流限幅）。
6. **示教手势与驾驶档不冲突**（已改为 左[中]+右[下]）；单板直控构型仍是 左[下]+右[下]，若切回该构型请注意。
7. **摩擦前馈是"方向性常值"**，低速时实际转速会略快于指令（指令 −10.3°/s → 实际 −18°/s）；要更线性可改成"比例+上限"。
8. 仿真/无硬件验证过的部分：`GIMBAL_YAW_POSITION_LOOP`、`GIMBAL_YAW_FEEDBACK_IMU` 两条回退路径**当前参数未整定**，启用前先按 °/s 量纲重算增益。
9. **小陀螺的两处遗留**：① 该档平移系数 `5.0`（其它档 `25.0`）⇒ 前进速度只有 1/5；② 推着左杆时瞄准速率 = 摇杆 + 底盘自转（保持环让位），若要"指哪走哪"需再补一项底盘自转速率前馈。
10. **烧录前先确认 J-Link 挂在哪块板**：工具按当前 ELF 解析符号、写的就是挂着的板；换板型后符号会静默错配（§2 末尾给了两条 30 秒自证判据）。
13. **"只用大yaw 电机当世界基准"做不到（原理）**：它的编码器只能测"云台相对底盘"的角；底盘自转时云台跟着转 ⇒ 读数恒定 ⇒ 底盘自转对它是**不可观测**的。"让大yaw 空着靠惯性当基准"也不行：本轴静摩擦大，自由云台几十毫秒就被拖同步（§9.24）。
11. 本次上电日志出现 `E:[BMI088] Calibrate Failed after 6 tries! Use offline params`（连续 5 次 `calibration was interrupted`）：IMU 仍可用（`IMU_Available=1`、`BigYaw` 有限），但零飘用的是离线参数。**上电后尽量别动整车**，让它把零飘标定跑完。
12. **（可选加固，未实现）** 若 IMU 通信中途失效，`BigYaw_Feed` 会**冻结在最后一个值**（不是 NaN，`isfinite` 兜不住）：此时保持环拿着恒定反馈，误差被"推杆时重刷目标"限制在一个小值上 ⇒ 最坏是几十 °/s 的缓慢自转（可用急停/左开关恢复），暂不加自检。真要加固可加"电机在转(>30°/s)但 `BigYaw` 连续 200 ms 不动 ⇒ 判定姿态冻结、关闭保持环"。

## 10. 2026-10-20 云台控制修复（大yaw / 小yaw / pitch / 小陀螺）

**背景**：云台板已装到**小yaw 转台**上（随大yaw+小yaw 转、不随 pitch 关节转）。由此产生一条硬约束：
IMU 的 `Pitch` **不是**枪管俯仰角 ⇒ pitch 反馈必须用 DM4310 编码器。

### 10.1 改了什么

### 10.2 上电前必做（符号自检，约 10 分钟）

1. 手转枪管上行，看 1Hz 日志 `[gimbal] pitch ref=… fb=…` 里 `fb` 是否**增大**。
2. 若与"给正力矩 → 枪管上行"相反：把 `gimbal.c` 的 `.feedback_reverse_flag` 在
   `FEEDBACK_DIRECTION_NORMAL / _REVERSE` 之间对调，重新编译刷写。
3. 定 `GIMBAL_PITCH_GRAVITY_DIR`：先把 `GIMBAL_PITCH_GRAVITY_A` 置 0 确认 PD 能大致悬住；
   再取 1.0 起加，观察是"更容易抬住"还是"越补越往下掉"，掉就取反。

### 10.3 验收（无视觉、无打靶）

- 观测日志（1Hz，限频）：`I:[gimbal] pitch ref=… fb=… ff=… mNm | yaw spd_ref=… fb=… ff=… | sy ref=… fb=…`
  （`ref/fb` 单位 mdeg；`yaw fb` 是 °/s×1000；`ff` 是电流前馈量）
- pitch 静止 60s：`ref-fb` < 300 mdeg，无持续抖动/蜂鸣。
- pitch ±10° 阶跃：300ms 内跟上，超调 <15%。
- 小yaw 反复切档 10 次：使能瞬间位移 <2°，不撞限位，无保护停机。
- 大yaw 打杆 50°/s：300ms 跟上；松杆 0.3s 停住，无往复。
- 小陀螺空转 30s：枪口朝向漂 <3°，`spin FF learned` 收敛且量级 ≈ 底盘实际自转。

### 10.4 回退

- pitch 回 IMU 反馈：注释 `GIMBAL_PITCH_FEEDBACK_MOTOR`（仅当板子装在**随 pitch 转**的部件上才正确）。
- 重力前馈：注释 `GIMBAL_PITCH_GRAVITY_FF`，并把 `angle_PID.Ki` 改回非 0。
- 大yaw 前馈滞回：`GIMBAL_YAW_FF_ON/OFF` 设成同值即退化为单点比较；`GIMBAL_YAW_FRICTION_FF` 可回 2500。
- 小陀螺前馈：注释 `GIMBAL_YAW_FF_ON_IMU_LOST`，保持环恢复纯 P（稳态偏差回到 ω/Kp）。
- 平移系数：`CHASSIS_VXY_SCALE` 改回 5.0（仅小陀螺档要单独改时，把 `robot_cmd.c` 里那一处改回字面量）。
