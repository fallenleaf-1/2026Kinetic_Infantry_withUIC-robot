# 底盘舵轮 PID 调参指南

> 适用代码：`chassis-board-fix` 分支的 `application/chassis/chassis.c`（所有 PID 参数集中在 `ChassisInit()`）。
> 行号以当前版本为准，后续改动会有偏移，以参数名为准。

---

## 1. 控制结构总览

```
遥控器/视觉 → robot_cmd(云台板) --CAN--> chassis_cmd_recv(底盘板)
                                            │
                    ┌───────────────────────┼──────────────────────┐
                    ▼                       ▼                      ▼
            CHASSIS_FOLLOW 跟随PID     运动学解算              CHASSIS_ROTATE
            offset_angle(°) → wz       (舵向角 + 轮速)         wz=25(定值)
                    └───────────┬───────────┘
                                ▼
        ┌───────────────────────────────────────────┐
        │  GM6020 舵向电机(×4)     串级,1kHz          │
        │  角度环 ──► 速度环 ──► 电流指令(±30000)     │
        │  (total_angle°)  (speed_aps deg/s)         │
        ├───────────────────────────────────────────┤
        │  M3508 驱动电机(×4)      单速度环,1kHz      │
        │  轮速参考 ──► 速度环 ──► 电流指令(±16384)   │
        │  (摇杆计数量纲!)  (转子 speed_aps deg/s)    │
        └───────────────────────────────────────────┘
```

### 四个环的量纲（调参前必须清楚）

| 环 | 参考(输入) | 反馈 | 输出 | 位置 |
|---|---|---|---|---|
| GM6020 角度环 | 目标多圈角 (°) | `total_angle` (°, 多圈累加) | 速度环参考 (°/s, 限幅 MaxOut=3000) | chassis.c `angle_PID` |
| GM6020 速度环 | 角度环输出 (°/s) | `speed_aps` (°/s, **转子**) | 电流指令 (限幅 MaxOut=20000, 物理极限 ±30000) | chassis.c `speed_PID` |
| M3508 速度环 | 轮速参考（**摇杆计数**，单轮限幅 16500） | `speed_aps` (°/s, **转子**) | 电流指令 (限幅 MaxOut=15000, 极限 ±16384) | chassis.c `speed_PID` |
| 底盘跟随 PID | `offset_angle` (°, ±180) | 0 | wz（进入运动学，预缩放后量纲） | chassis.c `Chassis_Follow_PID` |

**注意**：M3508 的参考值是摇杆原始计数（×25 后 ±16500），反馈却是转子 deg/s，两者量纲不一致，纯靠 Kp 软匹配。换轮径/减速比后 Kp 必须重调。

## 2. 调参前安全准备

1. **整车架空**，轮子离地（舵向电机扭矩大，连杆可能伤人）
2. **遥控器左上开关拨到[上]（急停）**，再上电；确认 RTT log 无 `[dji_motor] ID crash` / `Motor lost` / `can comm lost`
3. **一次只测一个电机**：其余电机保持零力（可临时注释掉其他电机的 `DJIMotorEnable`，或用模式选择）
4. **MaxOut 是电子保险丝**：首次给闭环时先把 MaxOut 减到最终值的 1/3，确认转向和响应正常后再放开
5. 观察手段：肉眼 + 手机慢动作摄像；有条件用 RTT 输出 `measure.total_angle`/`speed_aps` 画曲线
6. 改参数 → **Keil 重新编译烧录**才生效（参数都是编译期常量）

## 3. 调参顺序（串级从内到外）

```
① GM6020 速度环(内环) → ② GM6020 角度环(外环) → ③ M3508 速度环 → ④ 底盘跟随 PID(需整车+云台)
```

**通用方法（先 P 后 I 再 D）**：
- **Kp**：从小值起，逐步增大到系统出现**等幅振荡**，然后**回退 30%~40%**
- **Ki**：只有存在稳态误差（到位慢/差一点）时才加；从 0.1×Kp 量级起步，逐渐加大；出现超调加剧或低频摆动就退
- **Kd**：出现超调或到位前振荡时加；从 0.01×Kp 量级起步。角度环已启用微分先行（`PID_Derivative_On_Measurement`），对参考突跳不敏感，可放心加
- **每改一次参数**：观察 阶跃响应的 上升时间 / 超调量 / 稳态误差 / 有无啸叫

## 4. 各环具体步骤

### ① GM6020 速度环（chassis.c `speed_PID`，当前 Kp=10 / Ki=0.1）

1. 临时让角度环直通：把 `chassis_vector_to_GM6020_wheel_angle_ecd` 的输出固定（或在 `LimitChassisOutput` 里临时 `DJIMotorSetRef(servo_lf, 500)` 给定一个固定速度参考 500°/s）
2. Kp 从 2 开始：给 ±500°/s 阶跃，看转速表/听声音
   - 响应慢、爬升 → Kp ↑（每次 ×1.5）
   - 啸叫/抖动 → Kp ↓
3. 到能够快速跟上阶跃（上升时间 < 100ms、无持续振荡）后，回退 30%
4. Ki 加到 0.1~0.5，观察小信号下是否消稳态差；不需要就置 0
5. 记录最终值，恢复角度环

### ② GM6020 角度环（chassis.c `angle_PID`，当前 Kp=50 / Ki=5 / Kd=1，MaxOut=3000）

1. 恢复正常舵向控制，用遥控器给定角度阶跃（小行程快速拨杆，目标摆动 ±30° 左右）
2. 先只保留 Kp（Ki=0, Kd=0）：Kp 从 10 起
   - 到位慢、软绵绵 → Kp ↑
   - 接近目标时来回摆 → Kd ↑ 或 Kp ↓
3. Kd 从 0.5 起：抑制末端振荡；注意微分已作用于测量值，参考突变不会打微分
4. Ki 最后加（5 起步）：消除摩擦带来的稳态角差；IntegralLimit=1000 已限制积分膨胀，若仍出现缓慢摆动则减 Ki
5. **四个舵向电机参数相同**，但机械摩擦不同，若某个轮稳态差明显，优先检查机械而不是加积分
6. 验收判据：60° 阶跃，到位时间 ~0.3s，超调 < 10%，无啸叫

### ③ M3508 速度环（chassis.c `speed_PID`，当前 Kp=3 / Ki=0 / LPF_RC=0.3）

1. 单轮驱动测试：固定轮向（舵向 0°），小轮速给定（如 5000 计数）
2. Kp 从 1.5 起，方法同①；M3508 减速比 19，反馈是转子速度，数值很大，Kp 不需要大
3. `Output_LPF_RC = 0.3`：输出低通滤波，**越小越平滑但响应越钝**。若加速"肉"，增大到 0.5；若电流啸叫，减小到 0.1~0.2
4. Ki 默认 0：四轮负载接近时不需要；若某轮带载爬速慢，统一加 Ki=0.2 左右（IntegralLimit=3000 已设好）
5. 四轮两两一致性检查：同给定下四轮 `speed_aps` 相差 < 5%

### ④ 底盘跟随 PID（chassis.c `Chassis_Follow_PID`，当前 Kp=1.25 / Ki=60 / Kd=0.0004）

> 前提：①②③已调好，云台板+底盘板双板联调。

1. 跟随模式（左开关[下]），手转云台一个小角度后松手，观察底盘回正
2. Kp=1.25 起（理论预缩放值）：
   - 回正慢 → Kp ↑
   - 回正时冲过头再摆 → Kp ↓ 或 Kd ↑（0.0004 起，×2 递增）
3. Ki=60 负责消除小角度死区（配合变速积分，仅 |误差|<1° 时全积分）：若最终差 2~3° 回不到位，Ki ↑；若在零位附近缓慢摇摆，Ki ↓
4. 注意 CoefA=CoefB=0：变速积分在 |误差|≥1° 时若积分累积趋势存在则直接置零（积分分离），大偏差下靠纯 P 快速回正
5. 验收判据：云台转 90° 后松手，底盘 <1s 回正、超调 < 5°、无绕圈

## 5. 症状 → 调整对照表

| 症状 | 原因 | 调整 |
|---|---|---|
| 高频啸叫/电机抖动 | Kp 过大 | Kp 减半，逐步回调 |
| 响应慢、软绵绵 | Kp 过小 | Kp ×1.5 递增 |
| 到位慢且差一截不走了 | 无积分/积分太弱 | 加 Ki；确认 IntegralLimit > 0 |
| 接近目标时来回摆 | 阻尼不足 | 加 Kd（角度环）或降 Kp |
| 零位附近缓慢画圈摇摆 | 积分膨胀/ Ki 过大 | 减 Ki 或减 IntegralLimit |
| 加速"肉"、无力 | 输出限幅太小或 LPF 太钝 | 查 MaxOut；Output_LPF_RC 增大 |
| 单轮异响、其他轮正常 | 机械问题优先 | 检查联轴器/轴承，别急着调参 |
| 小陀螺时车不走直线 | 运动学/舵向零点问题 | 回查 GM6020_xx_ANGLE 零点标定 |
| 云台断电后底盘停（1s 内） | 断链保护生效 | 正常行为 |

## 7. 场测验证顺序

1. **零力检查**：上电默认不动；遥控器左上急停一切电机
2. **单轮舵向**：分别给定每个舵向 ±90° 阶跃，观察响应一致性
3. **低速平移**：不跟随模式（右开关[中]），摇杆小幅四方向平移，四轮舵向应始终指向合成速度方向
4. **边走边打杆**：平移中改变方向，舵向应平滑过渡（无 180° 跳变顿挫；有翻转属正常，但不应反向推车）
5. **自旋**：右开关[上]，纯自旋绕几何中心；wz=25 若转太慢/太快，按第 6 节行号微调
6. **跟随**：右开关[下]，转云台看底盘回正
